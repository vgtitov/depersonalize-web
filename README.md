Страница, которая прячет в тексте, таблице Excel и документе Word имена, телефоны, почту, организации и пароли, прежде чем вы отправите файл нейросети. Ответ ИИ можно вернуть обратно с настоящими значениями. Всё происходит в вашем браузере.

> **Это не гарантия приватности, а снижение риска.** Страница ловит типичное, но что-то пропустит. Перед отправкой посмотрите безопасную копию глазами: должность, редкое событие, сумма могут выдать человека.

Откройте [страницу на GitHub Pages](https://vgtitov.github.io/depersonalize-web/) или `index.html` двойным щелчком. Нажмите «Показать на примере» на любой вкладке, чтобы за минуту увидеть, как это работает.

## Как пользоваться
Три вкладки: **Текст**, **Excel**, **Word**. На каждой четыре шага.

1. **Загрузите или вставьте.** Текст вставляется в поле, Excel (`.xlsx`, `.csv`) и Word (`.docx`) выбираются файлом.
2. **Выберите, что скрыть.** В тексте и Word страница заменяет найденное сама. В Excel для каждой колонки вы выбираете: оставить, заменить на коды, убрать колонку или найти и скрыть внутри текста ячеек. Тип колонки (ФИО, телефон, почта, организация) страница угадывает, это подсказка.
3. **Скачайте безопасную копию** (и сохраните **ключ**, файл `ключ-обезличивания-<номер>.json`). Имя копии всегда одно и то же («документ-безопасная-копия.docx», «таблица-безопасная-копия.xlsx»), потому что в имени исходного файла бывают ФИО. Копию отправляйте в ИИ. Ключ остаётся у вас: в нём настоящие данные.
4. **Когда ИИ ответит, верните имена.** Вставьте ответ (или файл `.xlsx`, `.csv`, `.docx`) и, если страницу закрывали, загрузите ключ. Коды вроде `ЧЕЛОВЕК_001` или `[ЧЕЛОВЕК_1]` заменятся настоящими значениями. Страница покажет номер ключа, сколько кодов нашлось в ответе и сколько из них не из этого ключа: если не из этого, вы, возможно, загрузили ключ от другого документа. Новая обработка во вкладке заменяет ключ в памяти (страница предупредит), поэтому сохраняйте ключ каждого файла.

В Excel один и тот же человек или значение получает один и тот же код во всех строках, поэтому ИИ может считать, группировать и сравнивать, не видя настоящих имён. Необязательный «словарь» наверху страницы: впишите важные имена и названия проектов, они заменятся вместе со склонениями. Слова из двух букв («Ли», «Ян») заменяются только в том регистре, как вы их написали, без склонений; слова из одной буквы пропускаются, страница об этом скажет.

## Что находит
Имена и ФИО (падежи, инициалы, ПРОПИСНЫЕ, через дефис), один человек в разных формах получает одну метку; организации с формой собственности (ООО, ЗАО, ОАО, ОДО, УП, АО, ИП и др.); email; телефоны; ссылки; IP; ники; УНП и ИНН; номера карт; IBAN; номер паспорта РБ (серии MP, KH, AB и др.) и после слова «паспорт»; личный (идентификационный) номер РБ; дату рождения после слов «дата рождения», «родился», «д.р.»; адрес в виде «ул. Ленина, 15, кв. 3» (улица, проспект, переулок, бульвар, площадь, шоссе); пароли и токены после слов «пароль:», `pass=`, `token:`, `api key =`, Bearer, в адресе вида `user:пароль@сайт`, известные форматы ключей. Секреты в файл-ключ не попадают.

## Чего не умеет
- Косвенные признаки (должность, редкое событие, сумма) остаются.
- **Адрес** находится только в форме «улица/проспект/переулок + название + номер дома»; адрес словами («рядом с вокзалом»), без слова «ул.», населённый пункт без улицы и индекс остаются. **Дата рождения** находится только рядом со словами «дата рождения», «родился», «д.р.»: просто дата в тексте остаётся. **Паспорт** других стран и серии, которых нет в списке (MP, KH, AB, BM, HB, KB, MC, PP, SP), находятся только после слова «паспорт».
- Фамилия без характерного окончания (Кравец, Жук, Бондарь, Мельник) находится, когда стоит рядом с «Имя Отчество» («Кравец Олег Иванович»); одна, без имени, остаётся без словаря. Должности перед именем («Директор Олег Иванович») не затрагиваются.
- Фамилия без характерного окончания и организация без формы собственности находятся только по словарю.
- Пароль узнаётся по слову рядом («пароль», `password`, `token`, `pin`, «пароль от почты:» и т. п.). Без такого слова, а также пароль из нескольких слов без кавычек не узнаётся: «пароль: "correct horse battery"».
- Имя без фамилии («Мы с Ярославом») не заменяется, если его нет в словаре. Латинские имена (Ivan Sidorov) тоже только через словарь.
- Одинокая фамилия женского рода («Сидорова»), если в тексте есть и «Иван Сидоров», получит ту же метку, и при возврате подставится мужская форма.
- **Excel:** копия содержит только значения выбранного листа; имя листа заменяется на «Лист1», строка заголовков тоже проходит поиск. Колонки с текстом по умолчанию выставляются в «Найти и скрыть внутри текста»: проверьте выбор, числа и даты остаются как есть. Копия содержит только значения выбранного листа. Формулы, оформление, другие листы не переносятся, даты станут текстом ГГГГ-ММ-ДД (со временем ЧЧ:ММ), числа вернутся числами при обратной подстановке по файлу ключа. Колонки, которые вы оставили как есть, уходят в ИИ без изменений.
- **Word:** заменяются абзацы, таблицы, колонтитулы, сноски, комментарии; автор документа стирается. В изменённом абзаце оформление берётся от первого фрагмента. Надписи обрабатываются. Если в документе есть исправления (рецензирование), изменённые места сведутся в обычный текст, страница об этом предупредит. Подписи к картинкам (альтернативный текст), нестандартные XML-вставки и диаграммы тоже проверяются, но проверьте копию в Word. Картинки и вложенные файлы не анализируются (страница предупредит, если они есть). Вставки HTML или RTF внутри документа (редкие, их делают генераторы документов) тоже не обрабатываются, страница предупредит. Миниатюра первой страницы (`docProps/thumbnail`) из копии удаляется. Внешние ссылки (почтовые адреса и адреса сайтов) в документе тоже заменяются, поэтому ссылки в копии не работают.
- Обычное слово сразу после имени с заглавной («Анна План продаж…») может принять за фамилию и заменить везде: проверьте результат глазами. Имена закладок Word страница не меняет, а предупреждает.
- Тексты, которые нельзя отправлять вовсе (дети, здоровье, тайна исповеди), обезличивание не открывает.

Подробно: [SECURITY.md](SECURITY.md).

## Почему можно проверить
- Одна страница, код читается: `engine.js` (текст), `office.js` (Excel, CSV, Word), `ui.js` (кнопки). Они вставлены в `index.html` как есть, это проверяет тест.
- В `index.html` политика CSP `default-src 'none'`: браузер запретит любые сетевые запросы, даже если их добавят в код. Тест запрещает в коде `fetch`, `XMLHttpRequest`, `localStorage` и подобное.
- Нет CDN, аналитики, cookie. Единственная библиотека, JSZip, лежит в `vendor/` файлом.
- Откройте вкладку Network в инструментах разработчика: после нажатия кнопок она пуста. Или отключите интернет.

## Проверка и сборка
Нужен Node.js.
```
sh run_tests.sh              # тесты движка, Excel, Word, сборки
python3 tests/ui_check.py    # прогон страницы в Chromium со скриншотами (нужен Playwright)
sh build.sh                  # вставляет библиотеку и скрипты в index.html после правок
node example/make_examples.js   # пересоздать файлы для примера
```
Все примеры в тестах и в `example/` вымышленные.

## Пример для занятия
В папке `example/`: `пример-таблица.xlsx` (18 строк: ФИО, телефон, почта, организация, отдел, сумма, дата) и `пример-договор.docx`. Откройте страницу, вкладка Excel, выберите файл, скачайте безопасную копию, дайте её ИИ (например, «какой отдел принёс больше всего по сумме, назови клиентов по кодам»), ответ вставьте в блок «верните имена».
