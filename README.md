# Обезличивание текста в браузере

Страница, которая заменяет в тексте имена, телефоны, почту, реквизиты, организации и пароли на метки вроде `[ЧЕЛОВЕК_1]` до того, как вы отправите текст нейросети. Всё происходит на вашем компьютере.

> **Это не гарантия приватности, а снижение риска.** Страница ловит типичное, но что-то пропустит. Перед отправкой прочитайте результат глазами.

## Как пользоваться
1. Откройте `index.html` в браузере (или страницу на GitHub Pages).
2. Вставьте текст слева. Если знаете важные имена, фамилии, названия проектов, впишите их в «Словарь», по одному на строку: так ловятся и склонения.
3. Нажмите «Обезличить». Справа появится текст с метками, под ним счёт замен и предупреждения.
4. **Проверьте результат глазами**: не осталась ли фамилия, должность, редкая деталь, по которой человека можно узнать.
5. Скопируйте результат и отправьте в ИИ.
6. Ответ ИИ вставьте в блок «Вернуть имена» и нажмите кнопку: метки заменятся настоящими значениями.
7. Нужно вернуть имена позже или на другом компьютере: «Сохранить карту в файл» после обезличивания, потом «Загрузить карту из файла». В файле настоящие данные, храните его как секрет.

## Что находит
Имена и ФИО (падежи, инициалы, ПРОПИСНЫЕ), один человек в разных формах получает одну метку; организации с формой собственности (ООО, ЗАО, ОАО, ОДО, УП, АО, ИП и др.); email; телефоны; ссылки; IP; ники; УНП и ИНН; номера карт; IBAN; пароли и токены после слов «пароль:», `pass=`, `token:`, `api key =`, Bearer и известные форматы ключей (в карту они не попадают); слова вашего словаря.

## Чего не умеет
- Косвенные признаки (должность, редкое событие, сумма) остаются.
- Фамилия без характерного окончания и название без формы собственности ловятся только из словаря.
- Пароль без ключевого слова рядом не узнаётся.
- Файлы (docx, xlsx, сканы) не читает, только вставленный текст.
- Тексты, которые нельзя отправлять вообще (дети, здоровье, тайна исповеди), обезличивание не открывает.

Подробно: [SECURITY.md](SECURITY.md).

## Почему можно проверить
- Одна страница, код читается: логика в `engine.js` (около 110 строк), она же вставлена в `index.html`.
- В `index.html` политика CSP `default-src 'none'`: браузер запретит любые сетевые запросы, даже если их добавят в код.
- Нет внешних библиотек, CDN, аналитики, cookie и localStorage.
- Откройте вкладку Network в инструментах разработчика: после нажатия кнопок она пуста. Или отключите интернет.

## Проверка и сборка
Нужен Node.js.
```
sh run_tests.sh      # тесты
sh build.sh          # вставляет engine.js в index.html после правок
```
Тест `tests/t_build.js` падает, если `index.html` не совпадает с `engine.js`.

Все примеры в тестах вымышленные.
