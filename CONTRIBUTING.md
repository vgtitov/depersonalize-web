# Как внести вклад

Рады и людям, и ИИ-агентам. Нужны конкретные вещи: пропущенные или лишние замены, форматы файлов, которые не открываются, понятность для людей без технической подготовки.

## Быстрый старт
```bash
git clone https://github.com/vgtitov/depersonalize-web && cd depersonalize-web
sh run_tests.sh      # нужен только Node.js, всё должно быть зелёным
sh build.sh          # пересобрать index.html из исходников
```
Страница открывается двойным щелчком по `index.html`.

## Что приветствуется
- Пропущенные данные: форма имени, номера, реквизита, которую страница не узнаёт (с вымышленным примером).
- Ложные срабатывания: обычное слово принято за имя или реквизит.
- Excel и Word: случаи, когда файл не открывается или в копии остаются данные (метаданные, колонтитулы, примечания).
- Понятность интерфейса и текстов для неподготовленных пользователей.
- Тесты, документация, перевод.

## Правила для PR
1. **Никаких настоящих данных.** Только вымышленные имена, телефоны, адреса, организации. Файлы для тестов собираются кодом, не копируются из рабочих документов.
2. **Данные не уходят из браузера.** Ни сети, ни хранения, ни внешних скриптов (`sh run_tests.sh` это проверяет).
3. **Правь исходники** (`engine.js`, `office.js`, `ui.js`, `index.html` вне блока BUILD), затем `sh build.sh`: собранный `index.html` попадает в коммит.
4. **Тест на каждую правку.** Сначала тест, который падает, потом исправление.
5. **Честно про границы.** Не обещаем гарантий приватности, новые ограничения добавляем в `SECURITY.md`.
6. Тексты на русском, простыми словами, без жаргона.

## Процесс
Форк, ветка `fix/...` или `feat/...`, изменения, `sh build.sh`, `sh run_tests.sh`, PR по шаблону. Крупные идеи сначала в issue.

## Для ИИ-агентов
Репозиторий открыт для агентов. Читайте `AGENTS.md`, соблюдайте те же правила, можете открывать issue и PR.
